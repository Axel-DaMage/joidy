# Marcas registradas de terceros

La interfaz de Joidy menciona nombres y logos de productos y servicios de terceros únicamente con fines de **identificación** de las integraciones que el proyecto soporta o enlaza.

Todos los nombres de producto, logos y marcas aquí mencionados son propiedad de sus respectivos titulares. Su uso en Joidy:

- se limita a identificar la integración correspondiente;
- no implica respaldo, patrocinio ni afiliación con Joidy;
- no modifica ni distorsiona las marcas oficiales.

| Marca | Titular | Uso en Joidy |
|-------|---------|--------------|
| Google, Gmail, Google Calendar | Google LLC | Integraciones de Google (OAuth, tareas, calendario) |
| GitHub | GitHub, Inc. | Integración con repositorios y widgets del dashboard |
| Spotify | Spotify AB | Integración (enlace de cuenta desde Ajustes) |
| Strava | Strava, Inc. | Integración (enlace de cuenta desde Ajustes) |
| Telegram | Telegram Messenger Inc. / Telegram FZ-LLC | Integración con bot de Telegram |
| Obsidian | Obsidian (Dynalist Inc.) | Integración con el vault de notas |

Si eres titular de alguna de estas marcas y consideras que este uso no cumple las condiciones de referencia permitidas, abre un issue o escribe a [contacto@joidy.dev](mailto:contacto@joidy.dev) y lo revisaremos.
