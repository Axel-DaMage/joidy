# Comunidad

Joidy es un proyecto de conocimiento abierto. Hay varias formas de participar.

## Canales

- **GitHub Discussions**: para preguntas, ideas y anuncios.
- **GitHub Issues**: para reportar bugs o solicitar funcionalidades.
- **Pull Requests**: ver `CONTRIBUTING.md` para convenciones.

## Buenas primeras contribuciones

Busca issues etiquetados con `good-first-issue`.

Tipos de tareas ideales para empezar:

- Mejorar documentación (`docs/*`).
- Agregar tests (`test/*`).
- Resolver advertencias de accesibilidad o tipado en el frontend.
- Pequeños fixes de UI/UX.

## Código de conducta

Mantén un ambiente respetuoso e inclusivo. Consulta [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md) si existe, o sigue el estándar [Contributor Covenant](https://www.contributor-covenant.org/).

## Reconocimientos

Contribuidores se mencionan en `CHANGELOG.md` y en los créditos del release.
