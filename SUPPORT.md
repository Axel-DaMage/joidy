# Soporte

## Dónde pedir ayuda

| Necesidad | Canal |
|-----------|-------|
| Preguntas de uso, ideas, charlas | [GitHub Discussions](https://github.com/Axel-DaMage/joidy/discussions) |
| Reportar un bug | Plantilla de bug en [Issues](https://github.com/Axel-DaMage/joidy/issues) (ver [CONTRIBUTING.md](CONTRIBUTING.md#reportar-bugs)) |
| Solicitar una funcionalidad | Plantilla de feature request en [Issues](https://github.com/Axel-DaMage/joidy/issues) |
| Contribuir código | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Documentación | [`docs/`](docs/index.md) |
| Email | [contacto@joidy.dev](mailto:contacto@joidy.dev) |

## Vulnerabilidades de seguridad

**No abras un issue público.** Reporta vulnerabilidades siguiendo la [política de seguridad](SECURITY.md) (correo a [d4mag3@duck.com](mailto:d4mag3@duck.com)).

## Tiempos de respuesta

Joidy es un proyecto mantenido por una sola persona (ver [GOVERNANCE.md](GOVERNANCE.md)). No hay SLA de soporte: las preguntas y PRs se atienden según la disponibilidad del mantenedor.
